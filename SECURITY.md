# Security Policy

This repository contains personal portfolio content and **demonstration security labs**, not deployed services.

## Reporting a concern

If you discover a vulnerability or accidental sensitive disclosure, please do **not** open a public issue containing credentials, exploit data, or personally identifiable information. Contact the maintainer privately using the contact method on the [profile](https://github.com/MatthewAllen1). If GitHub private vulnerability reporting is enabled for this repository, prefer that channel.

Include the affected path, expected behavior, reproduction using non-sensitive synthetic data, and suggested fix.

## Scope and limitations

- All examples use fictional identities, safe sample data, and offline analysis.
- The code is educational and not designed as a replacement for a maintained SIEM, identity platform, or vulnerability management service.
- Do not submit employer-specific code, data, network details, credentials, or logs.
- Only test environments and assets you own or have explicit authorization to assess.
- All third-party contributions must respect original licensing and attribution.
